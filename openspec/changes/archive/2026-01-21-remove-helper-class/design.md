## 上下文

项目初始创建时包含了一个示例辅助类 `Helpers`，用于演示 C# 类库的基本结构。随着项目发展，这个类已经不再需要，但它仍然存在于源代码中，并且有对应的测试。

## 目标 / 非目标

- 目标：
  - 移除与项目核心功能无关的示例代码
  - 确保测试独立，不依赖源代码中的测试辅助类
  - 简化项目结构

- 非目标：
  - 不修改任何核心功能代码
  - 不改变测试框架或测试策略

## 决策

### 删除策略

直接删除 `src/Helpers.cs` 和 `tests/Helpers/HelpersTests.cs`，原因：

1. **示例性质**：`Helpers.Greet()` 纯粹是示例代码，不是库的功能
2. **无外部依赖**：没有其他代码引用这个类
3. **测试独立性**：测试应该专注于测试库的实际功能（Autofac 注解注册），而不是示例代码

### 考虑的替代方案

1. **保留并标记为内部**
   - 理由：可能对用户有参考价值
   - 未选择：源代码生成文档会包含它，造成混淆

2. **移动到示例项目**
   - 理由：保留参考代码
   - 未选择：项目目前没有示例项目，且示例过于简单

3. **移到测试项目**
   - 理由：测试可以引用
   - 未选择：违反测试应使用独立测试类的原则

## 风险 / 权衡

- **文档引用风险** → 需要检查 README.md 等文档，移除对 Helpers 的引用
- **用户中断风险** → 无，这是内部示例代码，不是公开 API 的一部分

## 迁移计划

### 步骤

1. 检查文档（README.md）是否引用了 Helpers 类
2. 删除 `src/Helpers.cs`
3. 删除 `tests/Helpers/HelpersTests.cs`
4. 运行测试验证其他测试不受影响
5. 更新文档（如有引用）

### 回滚

如果有需要，可以从 git 历史恢复 `Helpers.cs` 文件。
