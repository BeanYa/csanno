# 规范：代码清理

## 移除需求

### 需求：示例辅助类

**原因**：`Helpers` 类是示例代码，与项目的 Autofac 注解式组件注册核心功能无关
**迁移**：无（这是内部示例代码，不是公开 API）

#### 场景：删除示例代码

- **当** 项目删除 `src/Helpers.cs` 示例文件
- **且** 删除 `tests/Helpers/HelpersTests.cs` 测试文件
- **那么** 项目应该能够正常构建
- **且** 所有其他测试应该通过

### 需求：示例辅助类测试

**原因**：测试引用了不相关的示例代码，违反测试独立性原则
**迁移**：无

#### 场景：验证测试独立性

- **当** 删除 `tests/Helpers/HelpersTests.cs` 测试文件
- **那么** 不应影响其他任何测试的执行
