# library 规范

## 目的

定义 C# 类库项目的基础结构和配置规范，确保项目遵循现代 .NET 开发最佳实践。本规范涵盖了项目目录组织、编译配置、测试设置等核心方面，为 Csanno 类库提供标准化的开发基础。

## 需求
### 需求：项目结构
项目必须遵循标准的 .NET 类库目录结构。

#### 场景：查看根目录
- **当** 查看项目根目录
- **那么** 应包含 src/ 和 tests/ 目录

#### 场景：查看源代码目录
- **当** 查看 src/ 目录
- **那么** 应包含 .csproj 项目文件和源代码文件

### 需求：项目配置
项目必须启用现代 C# 开发特性。

#### 场景：查看项目配置
- **当** 查看 .csproj 文件
- **那么** 应启用 Nullable 引用类型
- **并且** 应启用 Implicit Usings
- **并且** 应使用最新 C# 语言版本

### 需求：测试项目
项目必须包含独立的 NUnit 测试项目。

#### 场景：运行测试
- **当** 执行测试命令
- **那么** NUnit 测试应能正常运行

#### 场景：测试项目引用
- **当** 查看测试项目
- **那么** 应正确引用源代码项目
